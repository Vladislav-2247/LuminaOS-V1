# LuminaOS

(на самом деле это все я делаю и буду делать сам.. 😅)

Для вас доступно в v1.0.0:

2. Настоящий Google браузер 
3. Игровой беслпатный сервис itch.io
4. Первый DEMO вирус
5. Системные приложения
И многое другое!

Последнюю версию можно скачать в разделе [Releases](https://github.com/Vladislav-2247/LuminaOS-V1/releases).  
Выберите `Lumina Setup 1.0.0.exe` для установки Lumina.exe
